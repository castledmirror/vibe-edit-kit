# Quickstart

1. Download this kit and open the folder in the Claude Code app and say: **set this up for me using ONBOARDING.md**
2. Open a folder of footage and say: **vibe edit this folder**

Finished clips land in `20_DELIVER/` inside your footage folder. They are ready to post.

Graphics are optional. If you want them on a clip, say: **add graphics to this clip**
